
# AWS Cloud Practitioner - Flashcards

Aplicação interativa de flashcards para apoiar os estudos para a certificação **AWS Certified Cloud Practitioner (CLF-C02)**.

## Acesso ao projeto

**[Acessar os flashcards](https://brunogacarvalho.github.io/aws-flashcards-cloud-practitioner/)**

## Conteúdo

O projeto reúne 328 cartões de estudo, organizados nos quatro domínios da certificação:

| Domínio | Cartões |
|---|---:|
| Conceitos da nuvem | 68 |
| Segurança e conformidade | 82 |
| Tecnologia e serviços AWS | 108 |
| Cobrança, preços e suporte | 70 |
| **Total** | **328** |

## Funcionalidades

- Navegação por domínio de conhecimento.
- Exibição interativa de perguntas e respostas.
- Filtros para todos, novos, difíceis e conhecidos.
- Embaralhamento dos cartões.
- Marcação do nível de conhecimento.
- Armazenamento do progresso no navegador usando LocalStorage.
- Contagem dinâmica dos cartões por domínio.

## Tecnologias utilizadas

## Objetivo

Reunir conceitos, serviços e fundamentos da AWS em cartões de revisão rápida, facilitando a memorização e a preparação para a certificação CLF-C02.
